# 多平台音乐数据爬虫

QQ音乐、网易云音乐、酷狗音乐三平台数据采集与可视化系统。

采集歌手歌曲的收藏量、评论量、热度指数、榜单排名等指标，通过 Web 界面展示数据变化报告和趋势图表。


## 快速开始

```bash
# 安装依赖
python3.9 -m pip install -e .

# 启动（开发模式）
python3.9 run_web.py --reload
```

浏览器访问 http://127.0.0.1:8000/

## 配置

```bash
cp .env.example .env          # API 基础配置（超时、QPS 等）
cp .env.qqmc.example .env.qqmc  # 业务参数（歌手名、新歌名、定时间隔等）
```

`.env.qqmc` 覆盖 `.env` 中同名键，已加入 `.gitignore`，适合本机差异配置。所有 `QQMC_*` 前缀变量控制业务行为，详见模板文件注释。

## 功能

- **歌手搜索** — 按名称搜索歌手，查看歌曲列表
- **抓取追踪** — 全量歌曲快照 + 指标变化检测
- **变化报告** — 按日/月/年维度展示收藏、评论等指标变化趋势
- **榜单监控** — 三平台榜单上榜检查与历史记录
- **新歌追踪** — 指定新歌的三平台收藏量曲线
- **热度查看** — QQ音乐/酷狗单曲热度指数、排名、趋势图
- **TOP N** — 收藏/评论排行

## 技术栈

- Python 3.9 / FastAPI + Uvicorn / Jinja2
- SQLite (WAL) + SQLAlchemy
- httpx / Playwright（热度数据）
- pydantic-settings / loguru / tenacity

## 数据存储

每个平台独立存储在 `data/` 目录下：

| 文件 | 说明 |
|------|------|
| `*_changes.db` | 指标变化记录 |
| `*_toplist.db` | 榜单数据 |
| `*_snapshots/` | 每次抓取的完整快照 |

## 定时任务

Web 启动后自动运行，无需额外脚本：

- 榜单拉取 — 三平台上榜检查
- 新歌更新 — 收藏量定时追踪
- 歌曲抓取 — 全量快照 + 变化检测
